SHIVKSU-NEXT custom manager and driver setup

This APK uses the existing locally generated signing key. Its matching drivers
trust that exact certificate and package. The keystore stays on the local PC.

Target driver matrix (each for ARM64 and x86-64):
  android12-5.10
  android13-5.10
  android13-5.15
  android14-5.15
  android14-6.1
  android15-6.6
  android16-6.12
  android17-6.18

The APK selects its matching driver for the detected kernel family, or the
kernel family explicitly selected by the user. Unsupported combinations stop
before the patch/flash command. Manually selected driver files remain available.
For an OTA inactive slot, explicitly select a driver for the updated kernel.

The recovery installer also selects the matching driver from the APK and returns
the actual installer result. Recovery installation has not been tested here.

Installing the APK alone does not replace a previously loaded kernel driver.
For initial setup, patch the correct stock boot/init_boot/vendor_boot image for
the particular device and firmware with this APK. A backup and a separately
reviewed device-specific flash step are still required. Direct install requires
working root access first. A .ko file must not be flashed directly to a partition.

This is support for the listed compatible GKI kernel families. It is not a claim
that every Android device, OEM kernel, locked bootloader, or 32-bit phone works.
Boot images are specific to a device and firmware; there is no universal boot image.

Build and APK identity checks can establish compilation, signatures, checksums,
and the packaged drivers' expected manager identity. They do not replace a
device boot/root test. No phone partition was flashed during this build.
